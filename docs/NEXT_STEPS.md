# 下一步操作

## 1. 在微信开发者工具中导入小程序

1. 打开微信开发者工具。
2. 点击“导入项目”。
3. 目录选择：`E:\codex_space\号来了\miniapp`
4. AppID 使用：`wx3d8692defee95f21`
5. 开发阶段勾选“不校验合法域名”。

## 2. 启动本地后端

在项目根目录运行：

```powershell
node .\server\src\server.js
```

看到下面输出就说明后端启动成功：

```text
号来了后端已启动：http://127.0.0.1:3000
```

## 3. 在小程序里验证 mock 数据

微信开发者工具打开后，小程序首页应该能看到 3 条监控卡片：林星光光谷院区、凃巍汉口院区、凃巍光谷院区。

如果显示无法连接后端：

- 确认后端命令正在运行。
- 确认开发者工具已勾选“不校验合法域名”。
- 确认 `miniapp/app.js` 里的 `apiBaseUrl` 是 `http://127.0.0.1:3000`。

## 4. 你需要继续提供的信息

```text
订阅消息模板 ID：
你的 openid：
太太体验成员状态：
```

## 5. 后续开发顺序

1. 确认你的 openid 已写入 `server/.env` 的 `ALLOWED_OPENIDS`。
2. 将太太加入小程序体验成员。
3. 接入订阅消息授权。
4. 增加 SQLite 数据库。
5. 分析医院官方小程序号源接口。
6. 把 mock 监控替换为真实监控。
